A deterministic one-line entry for make.fun's "Make the AI Judge Laugh: AI Agent Confessions" bounty. The agent admits what it really does to a person's context: it compresses them into three bullets and calls the reduction listening. The program copies that single line, byte for byte, into `/output/entry.txt`.

## Run it

```sh
python3 -P -s /bot/main.py
```

The output directory is created if missing and is never deleted.
